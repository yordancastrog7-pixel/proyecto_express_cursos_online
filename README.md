# Mi Proyecto — Cursos Online

Repositorio de entregas del bootcamp `bc-expressjs`. Cada semana desarrolla una parte
distinta de una **plataforma de cursos online**, aplicando los temas vistos sobre un mismo
dominio: `courses`, `students`, `enrollments`, `lessons`.

## Estructura

```
mi-proyecto-cursos-online/
└── week-01-nodejs_fundamentals/
    └── 3-proyecto/starter/    # CLI de procesamiento de datos — dominio: courses
```

Cada carpeta `week-01/` tiene su propio `README.md` con instrucciones específicas de esa entrega.
